Recreation of copter using jsgame0.js

The game screen appears here if your browser supports the Canvas API.

Use Z and X to move left and right, and SHIFT to thrust upwards. When you inevitably die, press SPACE to start a new game.

The recreation of copter using jsgame0.js is based on the description of the gameplay.
I was not able the reverse engineer the assembly code.

Play the original online.
